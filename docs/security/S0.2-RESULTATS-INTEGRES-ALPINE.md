## Incidents de qualification, tous corrigés sans modification métier

1. Première itération : la sonde de locale utilisait `SHOW lc_collate` non reconnu par PostgreSQL 18 ; remplacée par une lecture de `pg_database`. La recette métier avait réussi.
2. Deuxième itération : la sonde XLSX appelait une méthode `Row::getCells()` inexistante dans la version OpenSpout du projet ; remplacée par la propriété `Row::cells`, déjà utilisée par le code métier. **Aucun code applicatif modifié**.
3. Dernier passage `41229281239` : tous les contrôles expérimentaux réussis, sans échec technique.
